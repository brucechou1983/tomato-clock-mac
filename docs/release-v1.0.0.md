小番茄的第一個版本：用簡單的原生 Mac 介面專注工作，時間到了就起身動一動。

- 圓形倒數與專注／短休息／長休息模式，預設 25／5／15 分鐘，可自行調整。
- 專注結束時顯示獨立的起身提醒視窗；允許通知後也會收到系統提醒。
- 選單列計時、暫停／續跑、每 4 段長休息與今日完成統計。
- 深淺色模式、鍵盤快捷鍵與 VoiceOver 標籤。
- 不需要帳號或網路，設定與紀錄留在本機。

**安裝**：下載 `Tomato-Clock-1.0.0-arm64.dmg`，打開後把 app 拖曳到 Applications（應用程式）。首次開始計時時請允許通知。

**系統需求**：macOS 14 或更新版本、Apple Silicon。此版本未提供 Intel 安裝檔。

**簽名狀態**：使用 ad-hoc 本機簽名，尚未做 Developer ID 簽名或 Apple 公證。macOS Gatekeeper 可能阻擋網路下載的 app；信任來源的使用者可在「系統設定 → 隱私權與安全性」查看提示。

附上 SHA-256 校驗檔。12 項核心測試通過，原生 app 的起身與休息提醒視窗已完成實際操作驗證；系統通知橫幅未在隔離 UI 測試中啟用。
